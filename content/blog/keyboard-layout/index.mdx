I've been on a ZSA Moonlander for a while now. Programmable keyboards are one of those rabbit holes where the potential is basically infinite — you could spend months tuning layers, home row mods, combos, tap-dance keys. I've tried a lot of it. This is a post about pulling back from that and figuring out what I actually want.

## Layout philosophy

The first thing I had to accept is that more options isn't better. The Moonlander can do almost anything, and for a while I kept adding layers and shortcuts thinking I was optimizing. What I was actually doing was fracturing my muscle memory across a dozen half-learned patterns.

The goal I landed on: **keep it simple enough that I don't have to think about the layout at all.**

A few principles I'm working from:

**Preserve existing muscle memory where possible.** I came from a small keyboard that used `fn` for media controls and an arrow key layer. I'd rather carry that forward than retrain from zero on everything at once.

**Build better habits deliberately.** Arrow keys on `HJKL` is the main one — I want to move toward Vim-style navigation and a keyboard layout is a good forcing function. Same with growing into a numpad layer. These are intentional rewires, not accidental ones.

**Special characters are the hardest part.** For coding, brackets and symbols are constant. Getting those wrong — or requiring too much reach — causes real friction. This is where I'm being most careful.

## App hotkeys on the number row

One pattern I've been happy with: binding apps to the shifted number row (`!@#$%^&*()`) using Hyper as the modifier. The symbols map to the apps mnemonically, which makes them surprisingly easy to remember:

- `!` → Chrome *(the internet is exciting)*
- `@` → Slack *(@-ing people)*
- `#` → VS Code *(VS Code uses `#` for the symbol search)*
- `$` → terminal *(shell = money, roughly)*
- `%` → GitHub *(`%` often expresses difference; `git diff` is constant)*
- `^` → music *(caret looks like a music note, kind of)*
- `*` → password manager *(`****` is universal shorthand for a hidden password)*

It's a bit of a stretch on some of those, but that's the point — once you have a story for each one, even a silly one, it sticks. I can button-mash across the number row without thinking about it now.

Letter keys stay reserved for action-style shortcuts: `hyper+p` for a goto menu, `hyper+x` for clipboard history (X is cut), and so on.

## What's not working

The bottom row and inner thumb cluster keys are mostly dead to me. I tried putting Hyper on them but reaching still requires too much movement. The Moonlander's thumb cluster is bigger than it looks useful — in practice I only reliably use two or three of those keys.

The other pain point is `ctrl`. I'm still contorting my hand to hit `ctrl+something` combinations, and I think that's been the source of most of my actual discomfort. I haven't solved this cleanly yet.

Having `cmd` on the bottom row was also subtly discouraging me from resting my left thumb on the thumb cluster naturally. Small thing, but it compounded.

## Why I'm looking at the Voyager

Knowing which keys I don't want to use anymore has made me start resenting the ones that are there. The Moonlander is a big keyboard. The unused keys don't just sit quietly — they take up space on the desk, add to the visual noise, and remind me that I'm using maybe 60% of what I paid for.

A few specific things:

- **Tenting with an Allen key** is annoying. I adjust it occasionally and every time I have to go find the key.
- **Portability.** I've been working remotely more, leaving the house with a laptop more often. The Moonlander is not a travel keyboard.
- **Aesthetics.** This matters. I look at my desk all day. The Voyager is cleaner.

The Voyager is a smaller, more intentional version of the same idea. If I'm already not using a third of the Moonlander's keys, moving to a layout that doesn't include them seems like the honest next step.

## What I'm still figuring out

**Numpad layer.** I've set one up but reaching to the top-right cluster still involves more movement than I'd like. I haven't adapted to it yet.

**Thumb usage.** Right now my left thumb is underused. I want to shift spacebar to the left thumb and enter to the right — better balance, and it frees up some right-thumb real estate for other things.

**Home row mods.** I've experimented with these but haven't committed. The timing-based activation means you're always fighting the threshold between "I'm holding this key" and "I'm just a slow typer." Might be something to revisit on the Voyager with a fresh layout.

---

The through-line in all of this: I want a keyboard I've stopped thinking about. The Moonlander got me most of the way there. The Voyager might finish the job.
