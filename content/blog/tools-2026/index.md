Every year I do a loose audit of what's in my toolkit — not because I'm chasing new things, but because the tools that stick around deserve to be acknowledged. 2026 has been a notable shift for me. Some of this is new, some of it is just me finally committing to things I'd been dabbling with.

## Claude Code and opencode

These are the big ones. I've been testing both Claude Code and opencode — two AI coding tools that live entirely in the terminal. Claude Code is the one I've been using longer and it's genuinely changed how I work. It's not just autocomplete — it's more like pair programming with someone who has read your entire codebase. I can describe a problem, ask it to trace through multiple files, and get back something that actually understands the context.

What sold me was how it handles the boring parts: wiring up boilerplate, migrating APIs, tracking down where a bug is coming from. I can stay focused on the decisions that actually matter and let it handle the mechanical work.

I was skeptical of AI coding tools for a long time. I'm not anymore.

The funny side effect is that a lot of VS Code extensions have quietly become pointless. Linting integrations, import sorters, snippets — so much of that is just handled now. I still open VS Code occasionally but I'm spending most of my time in the terminal and I have complicated feelings about it. VS Code is a genuinely great editor and there's a small grief in realizing you don't really need it the way you used to.

## SuperWhisper

Voice input felt gimmicky to me until I tried SuperWhisper. Now I use it constantly — for drafting, for thinking out loud, for dictating long messages I'd have otherwise put off. The transcription quality is good enough that I'm not fighting it.

What's notable is that I'm running it with a local Parakeet model on the free tier. The quality has been excellent — and that matters because the alternatives I tried didn't stack up. Wispr Flow is polished but the pricing adds up fast. Handy I wanted to like but it never felt quite finished. SuperWhisper with Parakeet running locally hits a sweet spot: accurate, private, free, and it doesn't feel like a compromise.

The thing that surprised me is how much it changed my _thinking_ process, not just my typing speed. Speaking forces you to commit to a thought in a way that sitting at a keyboard doesn't. I end up with less half-finished sentences and more fully formed ideas.

## Raycast

Raycast has been my launcher for a while now but I keep finding new things in it. The extensions ecosystem is where it really shines — I have quick access to Linear, GitHub, snippets, unit conversions, and a dozen other things I'd previously context-switched out of my editor to do.

If you're still using Spotlight, just switch. It's not close.

## Linear

I've been switching from Asana to Linear and the difference is immediate. Asana is incredibly flexible — almost too flexible. You end up building your own system on top of it, which is fine until you realize you're spending energy maintaining the system instead of doing the work. Linear just gives you projects and issues and gets out of the way. For everyday development work, that's exactly the right model.

The developer-specific features are what really set it apart. Creating a PR with a Linear issue ID in the branch name automatically links it to the issue — it just works, no setup required. The MCP integration is excellent too, which means it slots right into LLM-based workflows without any friction.

The other thing I use constantly is the keyboard shortcuts. Command-K menus everywhere, quick issue creation, navigating between projects — it's the kind of keyboard-first UX that makes you realize how much time you lose clicking around in tools that weren't designed that way.

I use it for personal projects too now, not just client work. There's something clarifying about having a single place where work lives, even when you're working alone.

## Warp

My terminal of choice is Warp. It's fast, the block-based output makes scrolling through command history much more bearable, and the UX details are clearly thought through.

One thing I turned off almost immediately: the AI features. I know that sounds ironic given everything above, but in the terminal context it just got in the way. I know what I'm typing. I don't need suggestions there. Warp without the AI layer is still a better terminal than most.

I did try Ghostty briefly. The hype is real and the rendering is nice, but I bounced off it quickly — I couldn't drag panes around and that was a dealbreaker for me. Maybe I'll revisit it, but for now Warp stays.

## Figma

Still here, still the best. Nothing has come close to replacing Figma for UI design work. I've tried a few alternatives out of curiosity but always come back.

The thing I appreciate most is how little friction there is between a design and a conversation about it. Sharing a link, leaving a comment, handing off to a developer — it all just works. That might sound like a low bar but it's a bar a lot of tools don't clear.

---

The meta-observation I keep coming back to: the bottleneck has shifted. Coding itself takes less time now, which sounds like a win — and it is — but it's also exposed the parts of the workflow that were always slow and just hidden behind the slower coding pace. Requirements gathering, context switching, getting things into PRs and through review. Those haven't gotten faster. If anything they feel more prominent now because they're no longer dwarfed by implementation time.

I don't have a clean solution to that yet. It's the thing I'm actively trying to figure out in 2026.
